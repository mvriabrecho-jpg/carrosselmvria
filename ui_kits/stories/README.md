# UI kit — Stories (Instagram)
Modelos 1080×1920 para os stories, o canal principal da marca. **Criados do zero** a partir das diretrizes (nenhum story real foi fornecido).
- `StoryChegou` (peça nova, fundo rosé), `StoryTendencia` (radar, lavanda), `StoryCuidado` (bastidores de limpeza, branco), `StoryVendido` (preto).
Clique numa miniatura para ampliar. Blocos "Foto" são espaços para fotos reais.
