# Banco de imagens do MVRIA news

Fotos próprias da marca (arara, cabide, still de peças, etiquetas, loja), usadas
quando a busca de imagens livres não encontra nada bom para a semana.

- Formatos: `.jpg`, `.jpeg`, `.png` ou `.webp`, de preferência com 1600 px ou mais no lado maior.
- Nomeie pelo conteúdo (ex.: `arara-tricos-outono.jpg`, `etiqueta-burberry.jpg`); o nome ajuda a escolher a foto certa.
- Só coloque aqui fotos que a marca tem direito de usar.
