Main call-to-action button — black, square, uppercase tracked label.
```jsx
<Button>Comprar agora</Button>
<Button variant="secondary" iconRight="arrow-right">Ver curadoria</Button>
```
- `primary` (ink) for the single main action; `secondary` outline; `soft` rosé pastel for gentle actions (ex: "Quero saber mais"); `ghost` for text links.
- Sizes sm/md/lg (36/48/56px).
